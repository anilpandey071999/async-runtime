# Async Runtime

This project is a small runtime created for learning Rust. It provides a basic understanding of asynchronous programming in Rust.

## Features

- Basic async/await support
- Simple task scheduling
- Lightweight and minimalistic

## Getting Started

### Prerequisites

- Rust installed on your system. You can download it from [here](https://www.rust-lang.org/tools/install).

### Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/async-runtime.git
cd async-runtime
```

### Usage

To run the example:

```bash
cargo run --example basic
```
